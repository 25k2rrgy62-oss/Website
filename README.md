# GreenPear Studios

Static marketing site for GreenPear Studios' Roblox games. No build step — open `index.html` or serve the folder.

- `index.html` — page content (game names and copy are placeholders; edit freely)
- `styles.css` — design tokens at the top (`:root`)
- `script.js` — scroll reveals, word-by-word statement, sticky story, game picker

To link real games, replace the `href="#play"` / `data-roblox-link` links with your experience URLs.
